# Calculadora Web

Projeto de estudo feito com HTML, CSS e JavaScript puro.

## Como executar

Abra o arquivo `index.html` no navegador. Não precisa instalar dependências.

## Funcionalidades

- Soma, subtração, multiplicação e divisão
- Números decimais
- Limpar e apagar
- Suporte ao teclado
- Layout responsivo

As operações encadeadas são calculadas na ordem de entrada, como em uma calculadora simples.
